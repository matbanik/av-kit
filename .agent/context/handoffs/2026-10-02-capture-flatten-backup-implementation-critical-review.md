## Intent Anchor

MEU-67 `capture-flatten-backup` was supposed to deliver: saved overlay marks can be baked into the capture image, with a backup to revert from, across the API, MCP and GUI — a PNG flatten after a backup copy, a revert from the newest backup, `backup_path` on the detail, three `capture` settings, JPEG/WebP converted on Apply with the original untouched (A-2 Q1), Save overlay in PNG/JPEG/WebP (A-2 Q2), and the three file-destroying MCP actions (`remove`, `flatten`, `revert`) gated so that "AI agents should never be allowed to delete unless user explicitly instructs" — an IDE elicitation prompt, with the A-11 native-dialog fallback, that only an explicit human accept can pass. **Intent achieved: partial.** The file-level behaviour, the REST/GUI surfaces and the fail-closed outcome switch are delivered and proven against real Pillow, a real SDK client and the authoritative Windows gate/audit/look. The one gap is in the human-confirmation control itself: the text the person is asked to approve can be written by the agent (F1), which the plan's `USER_CONFIRM_MESSAGE` contract and D-24 explicitly forbid.

### Out-of-Contract Observations (not findings)

1. The prompt text is static with respect to `capture.flatten_backup` ("a backup is kept when backups are on"), and `avkit_settings set` is not a confirmed action: an agent can turn backups off, then ask to flatten, and the person accepts a prompt that reads as if a backup will be kept. Consider reading the live setting into the flatten message ("Backups are OFF: this cannot be undone") or adding `capture.flatten_backup` writes to `USER_CONFIRM_ACTIONS`.
2. `nativeConfirm` spawns `powershell.exe` with `{...process.env, AVKIT_CONFIRM_MESSAGE}` (`native-confirm.ts:72`), so `AVKIT_API_TOKEN` is inherited by the dialog process; the audit runner's own `ALLOWED_PASSTHROUGH_ENV` discipline (`SystemRoot`, `PATH`, `TEMP`, …) would do here too. Local-only.
3. The dialog is a focus-stealing TopMost `MessageBox` with `&Yes`/`&No` mnemonics: a `Y` keystroke typed into the IDE at the wrong moment accepts (default button is No, so Enter/Space decline). Mat's 2026-10-04 "flickered" No call (`walkthrough.md:440`) is consistent with a keystroke answering it. Residual risk of the A-11 design, accepted by the user's "local app" framing.
4. `advertiseSchemas` reaches into the SDK's private `server.server._requestHandlers` (`registry.ts:662`). The SDK is pinned at 1.30.0 and AC-67.34 plus a thrown "tools/list handler missing" make a rename fail loudly, so this is a maintenance note, not a defect.
5. `validate-task.sh handoff-ac` (`validate_closeout_artifacts.py --ac-coverage-only`) counts AC *prefixes* ("all 8 plan AC(s)"), so a dropped `AC-67.n` row is invisible to it (F2 got through). Review machinery; non-blocking per Materiality Gate #5.
