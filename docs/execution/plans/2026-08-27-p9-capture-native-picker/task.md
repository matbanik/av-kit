### Evidence-First & Sequencing Rules (v2.1)

- **Evidence-first completion:** a row is `[x]` only when its deliverable exists and the handoff carries the evidence bundle (AGENTS.md §Execution Contract).
- **Gates are proven before they are trusted.** Row 0 runs every `-SelfTest` negative oracle in this plan folder; row 0a proves the Verification Plan names only gate scripts that exist. A gate whose predicate matches zero rows, or that would accept a green suite as RED, an undeleted overlay as deleted, a handler delegating to the *wrong* controller method, a `dist` that merely echoes the build script's name, a neutralized E2E spec, or an unmeasured smoke, fails there rather than silently passing later. Round-4 hardening extends that to text that only *looks* like evidence: a commented-out or unreachable binding, a filter that matches zero tests, comment-only E2E markers, a required capture case that never ran, and a disposition citing a receipt that does not exist.
- **Task-row gate scope:** `assert-task-rows.ps1` proves **predecessor completeness** (`-Through <rowId>`), never global completeness — the row that runs the gate and every row after it are necessarily open at that moment. A missing `-Through`, an unknown boundary id, zero matched rows, or an empty predecessor set all fail. It also proves that each row in `TASK_ROW_REQUIRED_TOKENS` **invokes** its producer rather than merely naming it (round-9 finding R9-3): the token must be the command head, follow `&`, or be the value of a `TASK_ROW_INVOCATION_PARAMS` parameter - a path printed by `echo` or handed to another command as data does not close the row.
- **Status is parsed positively and fails closed** (round-4 finding R4-1). The status is read from the row's LAST cell, which must hold exactly one marker: only `[x]` and `[B]` are complete. `[ ]` and `[/]` block; a missing, decorated, duplicated, or unknown status is a hard error, never "assumed done".
