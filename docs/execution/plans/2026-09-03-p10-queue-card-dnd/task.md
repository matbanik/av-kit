### Evidence-First & Sequencing Rules (v2.1)

- **Evidence-first completion:** a row is `[x]` only when its deliverable exists and the handoff carries the evidence bundle (AGENTS.md §Execution Contract).
- **The review barrier resolves the reflection↔review cycle:** the handoff (H1-6) precedes the review; the reflection/metrics (H2) follow `approved` so they can record the verdict.
- **Self-review prohibition:** the implementing agent dispatches and collects the H1-7 review; it never authors the `approved` verdict.
- **`[B]` is evidence-gated:** valid ONLY for (a) a reproduced *external* error, (b) a missing dependency/credential/permission, or (c) a human-decision gate — each with a linked follow-up and, for (a)/(b), the pasted command plus a `VALIDATION_RECEIPT_DIR` receipt path.
- **The phase dividers above are ordering markers, NOT stop points.** Dispatching the H1-7 review is a blocking step, not a turn boundary: continue to H2 in the same pass once the `approved` verdict lands.
