The probe now seeds one shot and selects it, so `capture-tool-arrow` is enabled (title "Arrow") and the run tests the native tooltip itself rather than the disabled path.
- `nav-capture` has a `title` only while the rail is collapsed (`NavRail.tsx:70`), so the probe collapses the rail first.
