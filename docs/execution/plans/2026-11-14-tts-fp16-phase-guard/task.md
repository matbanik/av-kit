# Task — TTS FP16 phase guard spike (Session 73)

> **Project:** `2026-11-14-tts-fp16-phase-guard`
> **Type:** a spike on copies outside the checkout. It patches a copy of the FP16 graph with PHASE_GUARD, counts the denominators, compares the two graphs, runs the packaged 149-job sentences smoke on the original FP16, the guarded FP16 and INT8 on one fresh onedir, and builds one listening folder. Then D-797's outcome brief goes to Mat, and the records are written: 03's Delivered note, the register entry and MEU-127's status.
> **Estimate:** no product file changes. Written: `closeout-decisions.md` (new), 03's Delivered note, four keys of one register entry, `known-issues.md` (rendered), MEU-127's status and its renders, plus the project artifacts and the plan-local scripts written at plan time.
> **Working directory:** every command runs in `pwsh` from `P:/av-kit` on `main`, with `RECEIPTS_DIR=C:/Temp/av-kit` and `PYTHONIOENCODING=utf-8`. Receipts go to `C:/Temp/av-kit/s73-*`, and the run and model copies to `C:/Temp/av-kit/s73/`. `TMP` and `TEMP` are `C:\Temp\av-kit\s73\tmp`. `ELECTRON_RUN_AS_NODE` is cleared before every run.
> **Execution gate:** `plan_to_exec_gate: human`. Row 0 starts only after the plan review approves and Mat says to execute (plan §Status). The review loops have no token budget (`.agent/review-limits.json` `token_budgets: "off"`); their round caps are plan 3 and execution 6. No row commits, pushes, tags, releases, uploads, posts to Hugging Face or runs `npm run dist`. Only row 0b downloads, and only FRESH_INPUTS's seven files from Hugging Face at the app's pins (D-790 as ruled). Every other row is offline: the smoke runs the backend with dead proxies and its own `HF_HOME`. No row writes the system clipboard or runs the two clipboard Electron specs. Only row 0b reads `~/.avkit`, and only INSTALLED_READ's seven files there, to hash them (D-791 as ruled). No row reads the app database or Mat's settings file. Nothing touches the installed avkit MCP servers, and no other program is stopped (S13).
