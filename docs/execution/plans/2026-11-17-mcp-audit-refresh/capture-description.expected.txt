Call image to view a frame or sheet. To zoom, call sheet again with a narrower start and end; no state is kept between calls.
Workflow: capture or list → get/image → annotate. For a video: call avkit_convert probe for the duration, then avkit_capture sheet to find the moment, then frames for exact stills, then image to view a frame.
Prerequisite: local screen grab or inbox files; Capture never uploads YouTube.
Returns: JSON with path pointers, or image content for image.
Errors: TOOL_ERROR with envelope code and message; extra keys rejected before fetch.
image: variant=original|annotated. Optional x/y/width/height returns just that region from the full-resolution image, scaled to fit max_edge (default 1568; pass 2576 for high-resolution vision). Writes no file. Coordinates are original pixels, or unit: "fraction" (0–1) when you read them off a scaled view. The first content item gives the frame: source px = region.x + x / scale.
capture: mode=import copies a local image (png, jpg, jpeg, webp; absolute path) into the capture inbox as a new shot so image, crop and annotate work on it. The source file is never changed.
annotate: Example annotations: [{"type": "arrow", "from": [10, 10], "to": [80, 40], "color": "red", "stroke_width": 3}, {"type": "text", "x": 12, "y": 48, "text": "Note", "color": "white", "font_size": 16}]. A text mark's text may hold \n to start a new line; \r\n and \r are stored as \n, and lines never wrap.
flatten: Bakes the saved marks into the image file (backup first when capture.flatten_backup is on; a JPEG/WebP shot gets a new PNG copy instead); the user must also accept in the IDE.
revert: Overwrites the image file from its newest backup; the user must also accept in the IDE.
crop: Writes the region as a NEW shot (PNG) and returns its id and paths; the source is never changed. Same coordinates as image: original pixels, or unit: "fraction" (0–1). A box past the edge is clamped and `applied` reports what was cut. Saved marks are carried over and clipped to the region; `marks` counts kept, clipped and dropped. Optional name sets the file name (letters, digits, space, dot, underscore, hyphen). Like ImageMagick `-crop WxH+X+Y +repage`, without the virtual canvas.
frames: Prerequisite: a local absolute video path and FFmpeg; the video is read in place, never changed or uploaded. Returns: JSON with the video's duration and size and each new shot's id, path, time_ms and timecode; no image bytes. Give at (1-20 times: seconds, or "HH:MM:SS.mmm") or count (1-20 evenly spaced frames, with optional start and end). Each frame is the first one at or after its time; a time after the last video frame but before the end returns the last frame. Frames are new shots, so image, crop and annotate work on them. A raw stream with no duration takes only at, and is slow; remuxing it with avkit_convert add (fast copy) gives it a duration.
sheet: Returns: JSON with the video's duration and size, the new shot's id, path and size, spacing_ms and each cell's number, time_ms and timecode; no image bytes. One labelled grid image of a span (default the whole video): grid 2-5 (default 3, so 9 cells), max_edge 64-2576 (default 1568). Cells sit at the midpoints of equal parts of the span; each is the first frame at or after its time, and a time after the last video frame but before the end shows the last frame. Cite times from cells, never from the image. Events between cells can be missed. Needs a video with a duration.
export: Writes a resized or re-encoded copy as a NEW shot and returns its id, path, width, height and bytes; the source is never changed. format png, jpeg or webp. max_edge (64-16383) shrinks the long edge and never enlarges. quality (1-100, default 90) is for jpeg and webp only. Exports the shot as shown: the annotated image when it has saved marks, else the original. Keeps the colour profile and no other metadata. To get under a byte size, export again with a smaller max_edge or quality and check bytes.
