- **The review barrier resolves the old reflection↔review cycle:** the handoffs (H1-6) are created *before* the review (they are the review's input); the reflection/metrics (H2) are created *after* `approved` so they can record the verdict. Subjective reasons ("too complex", "no time", "out of scope", "later") are invalid; no error artifact ⇒ not blocked ⇒ keep working (AGENTS.md §Execution Contract).
