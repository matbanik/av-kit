Set up the av-kit MCP server for Claude Desktop (user scope: all projects).

Follow the steps in order. The server reads its own token from the app data folder, so no token goes in any config.

1. Find: the config file is %LOCALAPPDATA%\Packages\Claude_*\LocalCache\Roaming\Claude\claude_desktop_config.json if a %LOCALAPPDATA%\Packages\Claude_* folder exists (Claude Desktop installed from the Microsoft Store, MSIX); otherwise it is %APPDATA%\Claude\claude_desktop_config.json. Use that one file in every step below.
2. Back up: if the file chosen in step 1 exists, copy it to that path with .avkit-backup-<UTC yyyyMMddTHHmmssZ> appended, before changing it, with the current UTC time in that name. If it does not exist yet, skip the backup.
3. Merge: change only the avkit entry and keep every other entry. Add or replace the "avkit" key inside "mcpServers" with the one below and keep every other key. If the file does not exist, create it with exactly this content.

```json
{
  "mcpServers": {
    "avkit": {
      "command": "C:\\Program Files\\av-kit\\av-kit.exe",
      "args": [
        "C:\\Program Files\\av-kit\\resources\\mcp-server\\index.mjs"
      ],
      "env": {
        "ELECTRON_RUN_AS_NODE": "1",
        "AVKIT_APP_DATA": "C:\\Users\\Test User\\AppData\\Local\\av-kit"
      }
    }
  }
}
```

4. Restart: If the tools do not appear, quit and reopen Claude Desktop, then reply Ready.
5. Verify: call the avkit_health tool with action: "dependencies". It must return successfully. A "liveness" result never counts as verified.
6. Result: end your reply with exactly one line, either RESULT: connected or RESULT: failed (<step>, <error>), where <step> is backup, merge, restart or verify. When the verify call returns an error whose text starts with "<code>:", <error> is that code: an error starting "token_missing:" gives RESULT: failed (verify, token_missing).
